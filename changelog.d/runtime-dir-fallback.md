- Sessions without `XDG_RUNTIME_DIR` (Tailscale SSH, cron, `claude -p` from such a shell) now use the account's own `/run/user/<uid>` (#522): a remote `module install` / `update` / `hive-mind update` reaches the user systemd manager and restarts units, owner-agent clients find the agent's socket, and modules get the directory in `module run`, `status`, `doctor` and their CLI launcher. Only for the account's own login: a decoy or sandbox `HOME` gets no fallback, so test suites never reach the real manager. New stdlib helper `hive_runtime.py`.
