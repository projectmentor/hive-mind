- **Security: the sync daemon no longer echoes exception text to remote callers, and signs only fixed paths (SN-12, CK-6).** An unhandled error now answers HTTP 500 with `{"error": "internal error"}` and logs the exception to the daemon's own stderr. `sync_common.sign_hello` signs only for `/sync/hello` and `/hive/info` (and only for a hex nonce), so `/hive/info` never signs a caller-chosen string; the signed bytes stay under the `hive-hello-v1` domain. No wire-format change.
