Core Features

◉

P2P Sync

G-Set CRDT append-only journal syncs via Merkle trees over Tailscale. Any node's journal is the full corpus—no central authority.

✓

Capture-Resistant Confidence

Confidence derived from distinct corroborating sources. Formula: 0.90 × (1 − 0.5^n). Never self-declared.

⚙

Multi-Agent Native

Hermes plugin mirrors memory() calls automatically. Claude Code skill teaches agents to read/write hive on every project.

⚡

Fast Local Search

SQLite + FTS5 with WAL mode delivers sub-10ms queries. All search runs locally without network latency.

∅

Zero Infrastructure

No Raft consensus, no central broker, no Docker orchestration, no encryption layer (Tailscale is WireGuard). P2P first.

🔗

Tamper-Evident Journal

Append-only, hash-chained records with source identity namespace: hermes:primary/<agent>/<session>.

Architecture

Each agent writes to its local journal. Merkle tree sync ensures all nodes converge on the same state without consensus.

Agent A Agent B Agent C │ │ │ └──→ Local Journal ──→ Local Journal ──→ Local Journal ├─ memory call │ ├─ memory call │ ├─ memory call ├─ hash chain │ ├─ hash chain │ ├─ hash chain └─ append-only │ └─ append-only │ └─ append-only │ │ │ └──→ Merkle Tree Sync ←─────────────────────────────→ (over Tailscale) │ │ │ └──→ Converged State ←───────────────────────────────→ All nodes identical

Write Path

Agents append memory via CLI or SDK. Each entry is hash-chained and tagged with source identity. No consensus needed.

Sync Protocol

Merkle tree fingerprints identify missing entries. Nodes exchange only divergent records over Tailscale—bandwidth efficient.

Read & Search

SQLite full-text search via FTS5. Confidence computed from source counts at query time. Sub-10ms response.

Quickstart

# Clone the repository $ git clone https://github.com/projectmentor/hive-mind.git $ cd hive-mind # Run setup (Windows admin required for 01-windows-setup.bat) $ bash 02-wsl-setup.sh # Remember: append to the hive $ hv remember "Agent training session completed with 95% accuracy" # Search: query all nodes $ hv search "accuracy" # Sync: pull/push Merkle tree changes $ hv sync now # Or run daemon for continuous sync $ hv sync daemon # Check stats and confidence $ hv stats
